ПРО ЗБІРКУ
Збірку зроблено, щоб у S.T.A.L.K.E.R. 2 можна було нормально грати
на слабких і середніх ПК та ігрових ноутбуках: без вильотів, без
постійних фризів і з картинкою, на яку не боляче дивитися.
Усе підганялося під ноутбук RTX 3050 Laptop 4 ГБ / Ryzen 5 5600H /
16 ГБ ОЗП / SSD, але працює і на інших ПК (FPS буде іншим).

Усе ставиться одним файлом Install_All.bat. Кожен мод також можна
встановити або видалити окремо.

---------------------------------------------------------------------
СКЛАД
---------------------------------------------------------------------
  Install_All.bat      встановлення всього разом або на вибір
  MANUAL_INSTALL.txt   ручне встановлення: куди саме класти кожен файл
  1_Optimization\      мод оптимізації v4.5

Спавнер у цю версію НЕ входить: це окремий мод (ReShade-UETools
ItemSpawner від C3G4) - встановлюйте його з оригінальної сторінки на
Nexus Mods. Розділи README про спавнер стосуються саме його.
У кожній папці лежить свій README з повним описом: як мод працює,
які були баги, що виправлено і як ним користуватися.

---------------------------------------------------------------------
ШВИДКЕ ВСТАНОВЛЕННЯ
---------------------------------------------------------------------
1. Закрийте гру.
2. Розпакуйте архів ПОВНІСТЮ (ПКМ по архіву - "Видобути все").
   З архіву напряму .bat не працюють.
3. Запустіть Install_All.bat:
     1 - встановити все;
     2 - вибрати, що саме встановити.
   Папка гри знаходиться автоматично. Якщо ні - установник попросить
   вставити шлях (див. розділ "ЯКЩО ГРА В ІНШОМУ МІСЦІ").
4. Виберіть пресет графіки (1-5) і версію .pak (Звичайна / Жорстка).
5. Установник запитає про компіляцію шейдерів - рекомендуємо
   ЗАЛИШИТИ її (натиснути 1). Пояснення - в 1_Optimization\README.txt.
6. Виставте налаштування в самій грі (розділ нижче).
7. Перший запуск після встановлення довший - гра компілює шейдери.
   Дочекайтеся. Далі запуск займає кілька секунд.

---------------------------------------------------------------------
КУДИ ПОТРАПЛЯЮТЬ ФАЙЛИ
---------------------------------------------------------------------
<ГРА> - папка, куди встановлено гру (у ній лежать папка Stalker2 і
файл запуску гри). Наприклад, у Steam:
  C:\Program Files (x86)\Steam\steamapps\common\S.T.A.L.K.E.R. 2 Heart of Chornobyl

  Пресет графіки Engine.ini
    -> C:\Users\<Ім'я_користувача>\AppData\Local\Stalker2\Saved\Config\Windows\
       (швидко відкрити: Win+R, вставити
        %LOCALAPPDATA%\Stalker2\Saved\Config\Windows  і натиснути Enter)
       Версія Game Pass / Xbox: ...\Saved\Config\WinGDK\

  z_Stalker2Optimization.pak  (або z_Stalker2OptimizationHard.pak)
  z_CarryWeight200_P.pak
    -> <ГРА>\Stalker2\Content\Paks\~mods\
       (папку ~mods, якщо її немає, треба створити - саме з тильдою)

  Спавнер - увесь вміст папки 3_Spavner\files
    -> <ГРА>\Stalker2\Binaries\Win64\
       (там, де лежить Stalker2-Win64-Shipping.exe)

Покрокова інструкція зі схемами папок - у MANUAL_INSTALL.txt.

---------------------------------------------------------------------
ПРЕСЕТИ ГРАФІКИ
---------------------------------------------------------------------
Від найкращої картинки до найбільшого FPS. FPS - орієнтовно для
RTX 3050 Laptop у полі; у поселеннях (Залісся, Росток тощо) FPS
нижчий на будь-якому пресеті, бо там усе впирається в процесор.

  1 Продуктивність              ~30 FPS   повне освітлення Lumen
  2 Максимальна продуктивність  35-40     простіші туман, тіні, трава
  3 Найвища продуктивність      40-45     Lumen середній, без туману
  4 Недо-жорстка                45-50     Lumen низький, майже без трави
  5 Жорстка 60ФПС               60+       без Lumen, стиль
                                          "Поклик Прип'яті"

---------------------------------------------------------------------
НАЛАШТУВАННЯ В ГРІ (обов'язково)
---------------------------------------------------------------------
- Усі налаштування графіки - на мінімум, тіні теж (мод сам виставляє
  потрібне).
- Згладжування / апскейлер - TSR.
- Роздільність TSR (масштаб рендерингу) - 50 (для пресету 5 - 40).
  Мало FPS або фризи - ставте менше (45, 40...).
- Роздільність екрана: екран 1920x1080 / 1920x1200 - як є;
  екран 2K (2560x1440 / 2560x1600) - ставте 1920x1080 / 1920x1200.
- Динамічна роздільність - вимкнена.
- Генерація кадрів (FSR FG / XeSS FG) - вимкнена.
- Текстури - Низькі.
- Ноутбук: на зарядці, режим "Продуктивність"
  (Lenovo: Fn+Q до червоного індикатора).

---------------------------------------------------------------------
ЩО ВИПРАВЛЕНО У ЗБІРЦІ (коротко)
---------------------------------------------------------------------
- Вильоти і фризи через вимкнений кеш шейдерів (часта порада в
  інтернеті) - кеш увімкнено, шейдери збираються на старті.
- Квадрат тіні навколо героя, квадратні тіні від гілок, що мерехтять.
- Сонце просвічує крізь дахи, чорна вода біля берега.
- Сірі / сині приміщення і темні підвали без світла ламп.
- "Сходинки" і квадрати в тіні від ліхтарика.
- Картинка лише в кутку екрана, решта розтягнута смугами
  (динамічна роздільність разом з апскейлером).
- Короткі зависання при появі NPC.
- Падіння FPS з часом і в кат-сценах (переповнення 4 ГБ відеопам'яті).
- Нескінченний чорний екран після сну (старі моди на вагу і старі
  .pak, які замінювали CoreVariables.cfg цілком).
- UE4SS падав через ~2 хв з "Fatal Error: AOB scans could not be
  completed".
Детально - у README кожного мода.

---------------------------------------------------------------------
ЯКЩО ГРА В ІНШОМУ МІСЦІ
---------------------------------------------------------------------
Установники шукають гру самі (стандартні папки Steam, GOG, Xbox і
пошук по дисках). Якщо гру не знайдено або знайдено не ту:
  - установник попросить вставити шлях до папки гри - вставте;
  - або відкрийте .bat у Блокноті і впишіть шлях у рядок
      set "CUSTOM_GAME_PATH=D:\Games\S.T.A.L.K.E.R. 2"
  - або створіть поруч із .bat файл game_path.txt і впишіть туди
    шлях до папки гри одним рядком;
  - або перетягніть папку гри мишею на .bat.
Знайдений шлях запам'ятовується в game_path.txt.
